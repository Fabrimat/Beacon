# multipack worlds

`main/level.dat` is a minimal fresh Bedrock 1.21.50 flat creative world (storage version 10,
`LevelName`, `GameType`, `Generator=2`, seed, spawn, `experiments`, `abilities`,
`FlatWorldLayers`, `MinimumCompatibleClientVersion`, ...). There is no `db/`: the game
regenerates the world from `level.dat` alone. It deliberately has no `experiments.cameras`, so
the edition transforms must create it.

It is generated by Beacon's own NBT writer, not by the game: the generator is
`fixture_level()` in `crates/engine/tests/c1_common/mod.rs`. The test
`committed_fixture_is_the_generators_output` (`crates/engine/tests/c1_nbt.rs`) fails if the file
drifts from it; regenerate with

    BEACON_REGEN_FIXTURE=1 cargo test -p beacon-engine --test c1_nbt

`levelname.txt` is the game's plain `LevelName` copy; builds regenerate it.
